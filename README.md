# Time Planner

Веб-приложение для планирования времени и работы с задачами.

## О проекте

Курсовой проект на ASP.NET Core с разделением на модели, контроллеры, представления, ViewModel и слой работы с данными.

## Архитектура

- Controllers — обработчики HTTP-запросов;
- Models — модели предметной области;
- ViewModels — модели представления;
- Views — интерфейс;
- Data / Migrations — работа с базой данных;
- wwwroot — статические файлы.

## Стек

- C#
- ASP.NET Core
- .NET 8
- Entity Framework Core
- SQL Server
- Razor / CSS

## Запуск

Требуется .NET 8 SDK и доступная конфигурация базы данных.

```bash
dotnet restore
dotnet run
```
