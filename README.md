# Time Planner

> Веб-приложение на ASP.NET Core для планирования времени и работы с задачами.

## Архитектура

Проект организован по классической структуре ASP.NET Core:

- `Controllers/` — обработка HTTP-запросов;
- `Models/` — модели предметной области;
- `ViewModels/` — модели для представлений;
- `Views/` — Razor-интерфейс;
- `Data/` — доступ к данным;
- `Migrations/` — миграции базы данных;
- `wwwroot/` — CSS, JavaScript и другие статические ресурсы.

## Стек

- C#
- ASP.NET Core
- .NET 8
- Entity Framework Core
- SQL Server
- Razor
- CSS

## Запуск

Требуется .NET 8 SDK.

```bash
dotnet restore
dotnet run
```

Перед запуском проверьте строку подключения и настройки базы данных в конфигурации проекта.

## Назначение

Курсовой/учебный проект, демонстрирующий построение серверного веб-приложения с MVC, ViewModel и Entity Framework Core.

🟢 Содержательный учебный веб-проект.
